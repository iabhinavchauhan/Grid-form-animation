# Numbered Grid

A simple and interactive **Numbered Grid** project created using **HTML, CSS, and JavaScript**. The project displays numbered boxes in a clean grid layout with a simple animation effect.

## Features

- **Numbered Grid Layout**
- **Interactive Grid Animation**
- **Hover Effects**
- **Smooth Transitions**

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**

## How It Works

The project generates a grid containing numbered boxes. JavaScript is used to control the grid interaction and animation, while CSS provides the layout, styling, hover effects, and smooth transitions.
